Media queries
------------
help create a responsive website
@media(width 600px){
    div{
        background-color:red;
    }
}
@media(min-width :600px){
    div{
        background-color:red;
    }
}
@media(min-width:200px)and (min-width:300px){
    div{
        background-color:red;
    }
}

postions
---------

1.static -default postion(the top, right, bottom,left and z-index prop)
2.relative-ele is relative to itself.(the top, right,bottom, left)
3.absolute-postioned relative to its closest positioned ancestor.
4.fixed-positioned relative to browser.
5.sticky-positioned based on user's scroll postion.
